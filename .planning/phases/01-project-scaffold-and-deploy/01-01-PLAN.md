  <read_first>.planning/phases/01-project-scaffold-and-deploy/01-RESEARCH.md</read_first>
  <files>amplic-learn/package.json, amplic-learn/svelte.config.js, amplic-learn/vite.config.ts, amplic-learn/src/app.css, amplic-learn/src/routes/+layout.svelte, amplic-learn/src/routes/+page.svelte, amplic-learn/static/logo.svg</files>
  <action>
Run `npx sv create amplic-learn --template minimal --types ts` to scaffold. Then `cd amplic-learn && npx sv add tailwindcss`. Install fonts: `npm install @fontsource/inter @fontsource/poppins`. Replace adapter-auto with adapter-vercel: `npm install -D @sveltejs/adapter-vercel` and update svelte.config.js to use `import adapter from '@sveltejs/adapter-vercel'` with `kit: { adapter: adapter() }`.

Configure app.css with Tailwind v4 CSS-first approach using @theme block defining brand tokens:
- --color-azul-profundo: #0E1B33
- --color-azul-amplic: #2563EB
- --color-cian-senal: #06B6D4
- --color-gris-claro: #F4F6FA
- --font-heading: "Poppins", sans-serif
- --font-body: "Inter", sans-serif

Import @fontsource/inter (400, 500 weights) and @fontsource/poppins (600, 700 weights) in app.css.

Create +layout.svelte that imports app.css globally.

Create +page.svelte as the landing page: centered layout with bg-gris-claro, a simple text-based "AMPLIC" logo (use an SVG placeholder in static/logo.svg with the word "AMPLIC" in azul-profundo), the tagline "Amplificamos datos en decisiones" in font-body text-azul-profundo/70, and an "Entrar" button styled with bg-azul-amplic text-white rounded-lg hover state. The Entrar button links to /catalog (will be built in Phase 3).

Create static/logo.svg as a minimal SVG with the text "AMPLIC" in bold, using the azul-profundo color.
  </action>
