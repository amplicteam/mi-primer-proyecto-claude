<objective>
Build the user-facing entry flow: a 4-digit shared PIN gate, then an Amplic-branded
profile-selection screen with cards for Dharrell and Jose. Remember the PIN and the
last-used profile on the device, and provide a "Cambiar usuario" path back to selection.

Purpose: This is the vertical slice that makes the phase goal real — a co-founder opens
the app, gets past the PIN, picks their profile, and lands in their own session. It wires
the data layer (Plan 01 stores) to actual screens.

Output: A PIN store, two components (PinGate, ProfileCard), and a `/perfil` route that
runs the PIN -> selection -> active-session flow, plus a landing-page link into it.
</objective>

  <action>
    Create amplic-learn/src/lib/stores/pin.svelte.ts — a runes module store for the shared PIN
    (per CONTEXT "Access Protection"):
    - Define the correct PIN as a module constant `const CORRECT_PIN = "2024"` with a comment
      noting this is a light client-side barrier, NOT real security (2-user internal tool).
    - `$state` boolean `unlocked`, hydrated on init (browser-guarded) from localStorage key
      `amplic:pin-ok` (value "1" means previously unlocked on this device).
    - `tryUnlock(input: string): boolean` — compares input to CORRECT_PIN; on success sets
      unlocked=true and writes `amplic:pin-ok="1"` to localStorage (browser-guarded); returns
      the boolean result.
    - Import `browser` from "$app/environment"; guard all localStorage access.

    Create amplic-learn/src/lib/components/PinGate.svelte — 4-digit PIN entry:
    - Props via $props(): an `onunlock` callback fired when the PIN is accepted.
    - A 4-character numeric input (inputmode="numeric", maxlength 4). On submit, call the pin
      store's tryUnlock; on success call onunlock(); on failure show a brief inline error
      ("PIN incorrecto") and clear the field.
    - Amplic-branded: bg-gris-claro screen, card centered, font-heading title (e.g. "Ingresa el PIN"),
      azul-amplic submit button, focus:ring-cian-senal — mirror the landing page aesthetic.

    Create amplic-learn/src/lib/components/ProfileCard.svelte — a single profile card:
    - Props via $props(): `profile: Profile` and `onselect: (id: string) => void`.
    - Render a large clickable card showing the profile initial in a colored circle
      (use profile.color), the profile.name in font-heading, hover/focus states with
      cian-senal accent. Calls onselect(profile.id) on click. Keyboard-accessible (button element).
  </action>
