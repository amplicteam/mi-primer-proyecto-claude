# Mi primer proyecto con Claude Code

Este repositorio es un espacio de práctica para aprender a usar Claude Code y GitHub.

## ¿Qué es esto?

Un proyecto de ejemplo para aprender a:
- Usar Claude Code desde la terminal
- Crear ramas en Git
- Abrir Pull Requests en GitHub

## Cómo empezar

1. Instala [Claude Code](https://claude.ai/code)
2. Instala [Git](https://git-scm.com) y [GitHub CLI](https://cli.github.com)
3. Abre una terminal en esta carpeta
4. Escribe `gh auth login` para conectar tu cuenta de GitHub
5. Escribe `claude` y presiona Enter
